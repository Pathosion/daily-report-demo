# 業務日報デモ

予定を作成し、実績へコピーして差分を修正できる静的なデモアプリです。担当者と作業内容は架空のサンプルです。

## 起動

Python が使える場合、リポジトリの直下で実行します。

```powershell
python -m http.server 4181
```

ブラウザで `http://127.0.0.1:4181/` を開きます。ビルドは不要です。

## 操作

- 「予定」で予定を登録します。1件ずつ、またはまとめて「実績に追加」できます。
- 「実績・日報」で実際の時刻や作業名を修正し、総括を保存します。
- 「履歴」で保存済みの日報を探して開けます。

データはブラウザの `localStorage` に保存されます。ログインや他端末との共有はありません。画面下の「サンプルに戻す」で初期化できます。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `app.css` | スタイル |
| `app.js` | 画面の動作と保存処理 |
| `data.js` | 架空のサンプルデータ |
| `tests/smoke.mjs` | 主要操作のブラウザテスト |

## テスト

別のターミナルで上記の静的サーバーを起動したまま、以下を実行します。

```powershell
npm ci
npx playwright install chromium
npm test
```

配信する場合は、`index.html`、`app.css`、`app.js`、`data.js`、`_headers`、`robots.txt` を静的ファイルとして配置します。`_headers` と `robots.txt` は Cloudflare Pages 向けの検索除外設定です。

## 制約

このアプリは操作を確認するためのデモです。認証、サーバー保存、権限制御はありません。実データの入力や業務利用は想定していません。
